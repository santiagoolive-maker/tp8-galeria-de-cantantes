# Voces en escena

Proyecto del Trabajo Práctico 8: **La Forja Colaborativa - Git, GitHub, Fork y Pull Request**.

## Tema

Galería de cantantes. Cada persona que colabore debe agregar:

1-Su nombre en la lista de participantes de index.html
2-Una imagen propia dentro de la carpeta img
3-Una tarjeta en la galería usando exactamente la estructura comentada en index.html

## Criterios visuales

- Mantener la clase tarjeta y sus elementos internos.
- Usar imágenes horizontales y un texto de hasta dos oraciones.
- Incluir un texto alternativo (alt) descriptivo en cada imagen.
- No modificar el CSS salvo que sea necesario y se explique en el Pull Request.

## Cómo ver el proyecto

Abrir index.html en un navegador web.
